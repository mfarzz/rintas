# Rintas — deskripsi aplikasi dan arahan konsep logo

Dokumen ini menjelaskan karakter Rintas sebagai bahan berpikir sebelum memilih atau menyempurnakan logo. Ini bukan keputusan desain akhir.

## Rintas dalam satu kalimat

**Rintas adalah aplikasi Windows untuk membagikan file langsung dari laptop melalui tautan sementara, tanpa menyimpan salinan file di layanan cloud.**

Nama **Rintas** mengisyaratkan jalur singkat: dari file di laptop pengirim menuju penerima, dengan langkah sesedikit mungkin.

## Masalah yang diselesaikan

Saat ingin mengirim file, orang sering harus membuka situs, mengunggah file, menunggu proses selesai, lalu menyalin tautan. Rintas mempersingkat alur itu. Pengguna memilih file dari menu klik kanan atau ikon aplikasi di system tray; aplikasi membuat tautan dan menyalinnya ke clipboard. Penerima membuka tautan di browser untuk mengunduh.

File tetap berada di laptop pengirim. Rintas menjalankan server di latar belakang dan memakai Cloudflare Tunnel agar tautan dapat diakses melalui internet. Laptop dan koneksi internet pengirim harus tetap aktif selama file dibagikan.

## Pengalaman yang ingin terasa

1. **Cepat:** klik file, pilih **Bagikan dengan Rintas**, lalu tempel tautan.
2. **Ringan:** bekerja di latar belakang tanpa jendela terminal atau alur unggah yang panjang.
3. **Terkendali:** setiap tautan memiliki kunci acak, masa berlaku bawaan yang bisa diatur, dan dapat dicabut.
4. **Langsung:** file diambil dari laptop pengirim saat penerima mengunduh, bukan dari penyimpanan cloud Rintas.

Rintas bukan tempat menyimpan file permanen. Tautan berhenti bekerja saat masa berlakunya habis, dibatalkan, atau aplikasi ditutup.

## Kepribadian merek

- **Gesit dan jelas:** satu tindakan menghasilkan satu tautan.
- **Tangguh:** terasa seperti alat kerja yang bisa diandalkan, bukan mainan.
- **Ramah tanpa berisik:** tidak perlu banyak langkah atau tampilan yang ramai.
- **Modern dan mandiri:** pengguna memegang file serta kendali atas aksesnya.

Jika logo memakai gaya pixel, pixelnya sebaiknya terasa **sengaja dan rapi**: bentuk geometris yang tajam, ritme blok yang konsisten, serta siluet yang kuat. Gaya ini bisa memberi kesan dunia digital dan perpindahan data tanpa membuat Rintas terlihat seperti permainan retro.

## Gagasan visual yang relevan

Ini adalah bahan eksplorasi, bukan daftar elemen yang harus digabungkan sekaligus:

- **Huruf R:** titik awal yang kuat agar ikon mudah diasosiasikan dengan nama Rintas.
- **Lintasan atau arah keluar:** menunjukkan gerak file dari pengirim ke penerima.
- **Dua titik yang terhubung:** menggambarkan akses langsung antara dua pihak.
- **Potongan file atau lembar dokumen:** membantu menjelaskan fungsi berbagi berbagai jenis file, bukan hanya video.
- **Satu aksen pixel yang berpindah:** dapat menyiratkan proses berbagi tanpa harus menggambar panah besar.

Hindari logo yang hanya berupa awan, tombol upload, atau ikon video. Unsur itu dapat memberi kesan file disimpan di cloud atau Rintas hanya bekerja untuk video.

## Kebutuhan praktis ikon

Logo akan dipakai sebagai ikon aplikasi Windows, ikon di system tray, dan penanda di menu klik kanan. Karena itu:

- Siluet utama harus tetap terbaca pada **16 × 16** dan **24 × 24 piksel**.
- Gunakan sedikit warna dan kontras kuat agar jelas di latar terang maupun gelap.
- Jangan bergantung pada tulisan “Rintas” di dalam ikon kecil.
- Detail kecil boleh hilang saat diperkecil tanpa mengubah makna bentuk utama.
- Bentuk akhir perlu memiliki versi satu warna untuk situasi yang membatasi warna.

## Pertanyaan untuk memilih konsep

1. Apakah bentuknya masih bisa dikenali saat tampil sebesar ikon tray?
2. Apakah kesan utamanya **berbagi file secara cepat**, bukan menyimpan atau mengunggah ke cloud?
3. Apakah simbolnya cukup khas untuk dibedakan dari ikon aplikasi file lain?
4. Apakah tampilannya terasa kuat dan sederhana, sesuai nama Rintas?

## Kalimat brief untuk desainer

> Buat ikon pixel untuk **Rintas**, aplikasi Windows yang membagikan file langsung dari laptop lewat tautan sementara. Tampilkan kesan lintasan singkat, perpindahan data, dan kendali pengguna. Utamakan siluet geometris yang mudah dikenali pada ukuran 16–24 piksel. Hindari simbol cloud, upload, dan video sebagai bentuk utama.
